# Review: build-logic

Phạm vi: `build-logic/convention` (`tmdb.module`, `tmdb.detekt` và các `configureX()` trong `buildlogic/`).
Trạng thái: đã đọc hết build-logic; các mục dưới đây chờ quyết định. Cột "Trạng thái" ghi mục nào đã kiểm chứng.
